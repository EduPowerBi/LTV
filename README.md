# CONTEXTO
Análise de Lifetime Value (LTV) com SQL Server e Power BI
Projeto de Business Intelligence desenvolvido para analisar o Lifetime Value (LTV) dos clientes utilizando SQL Server, modelagem dimensional e Power BI. O objetivo é transformar dados transacionais em indicadores estratégicos que apoiem decisões de marketing e retenção de clientes.
